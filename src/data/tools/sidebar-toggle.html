Description
Sidebar Toggle Tool allows you to show/hide the Generate Window. The tool provides a visual toggle interface with keyboard shortcuts (Ctrl+B). You can click on the toggle switch to show or hide the Generate Window section. Use this tool from the sidebar to quickly access the Generate Window controls.
