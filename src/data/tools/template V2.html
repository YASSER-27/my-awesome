قوة CSS Grid في التوزيع التلقائي

خاصية repeat(auto-fit, minmax(280px, 1fr)) توزع البطاقات تلقائياً حسب عرض الشاشة دون الحاجة لكتابة media queries متعددة.

متغيرات CSS في بلوك :root

تخزين الألوان والقيم المتكررة في بلوك :root يجعل تعديل الثيم بالكامل من مكان واحد فقط ويحسن قابلية الصيانة.

Custom Scrollbar

Scrollbar مخصصة

هذه منطقة قابلة للتمرير تعرض شريط التمرير المخصص. الشريط بلون بنفسجي يتحول للتركواز عند التمرير.

يمكنك رؤية الشريط على الجانب الأيسر من هذا المستطيل. حاول التمرير لأسفل لرؤيته بوضوح.

يتم تخصيص الشريط بثلاث خصائص CSS فقط: track ووlumb وhover.

تمت إضافة لون بنفسجي للـ thumb مع border-radius دائري ليبدو عصرياً ومتناسقاً مع باقي التصميم.
